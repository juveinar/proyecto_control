# Configuración del Proyecto

Esta carpeta contiene archivos de configuración del proyecto de control de proyectos.

## Archivos

- **settings.json**: Configuración general del proyecto

## Estructura

Los archivos de configuración están organizados para mantener separada la configuración del código fuente principal.

## Uso

Los archivos de configuración son cargados automáticamente por la aplicación o pueden ser referenciados según sea necesario.
